# 星盒屋 STAR BOX

给 6 岁女儿做的盲盒收集互动网页：投星星币、摇盒、撕封条、开盖、四级稀有度演出、图鉴收集、星尘兑换、家长台补货与重置。

## 状态

- 当前阶段：正式版可玩（单文件交付）
- 交付物：`out/star-box.html`（双击即玩，离线可用，存档在浏览器 localStorage）

## 怎么玩

1. 双击 `out/star-box.html`。
2. 首页点「投币开盒」→ 在 6 格货架挑一盒 → 按住盒子摇 → 按住红封条往下拖 → 点盖子。
3. 拆到的卡自动进图鉴；重复的卡转成星尘，可在图鉴页兑换指定 R / SR。

**家长台**：首页右下角小齿轮 **双击** → 输入密码 `1234`。可补货、改每日星星币（1–9）、奖励 1 枚、编辑愿望券、开安静模式、长按 3 秒重开一局。

## 实现要点

| 项 | 说明 |
| --- | --- |
| 交付形态 | 单个 HTML，CSS / JS / 32 张卡面（base64）全部内嵌，零外部请求 |
| 稀有度 | 云朵 N 60% / 荧光 R 28% / 电波 SR 10% / 传说 SSR 2% |
| 温柔保底 | 5 次无 SR+ → 第 6 次必 SR+；15 次无 SSR → 第 16 次必 SSR |
| 分级演出 | N 飘入+彩纸 / R 翻面+霓虹扫光 / SR 紫光柱+速度线+震屏 / SSR 压暗→心跳×3→三帧闪切→金印→金雨 |
| 收集 | 4 系列 × 8 张，集齐解锁盲盒涂装；8/16/24/32 张有里程碑弹窗 |
| 补货 | 货架每次进入自动补满 6 格，不会有空格；家长台仍可手动整理 |
| 星尘 | 重复卡 N+5 / R+15 / SR+40 / SSR+100；120 换 R、320 换 SR，SSR 只能抽 |
| 护眼 | 扫描线不透明度 5.5%，无高频闪烁；安静模式关粒子与震屏、演出时长 ×0.62 |
| 音效 | WebAudio 实时合成，不含音频文件 |

## 结构

| 目录 / 文件 | 内容 |
| --- | --- |
| `index.html` | GitHub Pages 入口（自动跳转到 `out/star-box.html`） |
| `src/index.html` | 开发版入口（引用 parts / js，需本地起 http 服务） |
| `src/parts/*.css` | 基础层、界面层、演出与弹层 |
| `src/js/00-data.js` | 32 张卡数据、稀有度、愿望券默认值 |
| `src/js/10-audio.js` | WebAudio 音效 |
| `src/js/20-fx.js` | Canvas 粒子、彩纸、金雨、震屏、飞币 |
| `src/js/30-core.js` | 存档、导航、首页、货架、抽选与保底 |
| `src/js/35-open.js` | 摇盒 / 撕封条 / 开盖 / 稀有度演出 |
| `src/js/40-album.js` | 图鉴、卡片详情、星尘兑换 |
| `src/js/50-parent.js` | 家长台（密码、长按确认、愿望券） |
| `src/assets/cards/` | 原始卡面 1680×2240 |
| `src/assets/cards-web/` | 压缩卡面 560×748（打包用） |
| `scripts/build.ps1` | 合成单文件到 `out/star-box.html` |
| `docs/` | 设计稿、奖池清单 |
| `out/` | 交付成品 |

## 构建

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\build.ps1
```

开发时可直接在 `src/` 起静态服务预览：

```powershell
python -m http.server 8899 --directory src
```
