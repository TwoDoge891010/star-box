# 星盒屋 STAR BOX · 设计稿 v0.1

> 目标：给 6 岁女儿的幸运盲盒互动网页。核心不是「抽奖」，而是「拆开—惊喜—收好—再期待」。
> 设计稿地址：`out/design-draft/index.html`

---

## 1. 一句话概念

街角有一台用老电视机改装的盲盒机，里面住着会发光的星宠。投一枚星星币，拆开一颗星星，把它收进图鉴。

- **玩家**：6 岁，识字量有限，靠图形、颜色、声音理解；耐心短，需要即时回应。
- **陪伴者**：家长。负责补货、重置、改每日次数、兑现实体愿望券。
- **情绪目标**：每一次拆开都有回应；连续没抽到也不会挫败；抽到传说能被记住一整周。

---

## 2. 游玩循环

```
看货架 → 选一盒 → 摇一摇 → 撕封条 → 开盖 → 稀有度演出 → 卡片入册 → 攒星尘 → 兑指定款
                                                    ↘ 集齐一个系列 → 解锁新盒皮肤
```

单次时长 15–25 秒，一次坐下来玩 3 次约 1 分钟。**不做长留存任务链**，避免把小孩绑在屏幕前。

### 星星币与投币（v1.0 确认）

- 默认每天发 **3 枚星星币**，家长可改 1–9。
- 投币 = 一次抽奖机会：硬币从屏幕右上飞入投币口 → 叮当声 → 币仓数字 -1 → 机台亮灯 `READY` → 才能选盒。
- 用完后进入「星星充电」状态，显示倒计时，按钮变灰并说「明天再来」。
- 家长可在家长台「奖励 1 枚」，作为亲子任务的即时回报。
- **不设内购、不设失败**：投了币一定有东西，最差是星尘 + 贴纸。

## 3. 奖品分级

四档，名字用孩子能懂的自然物，不用 SR/SSR 术语（设计稿里保留英文代号做视觉标签）。

| 代号 | 名称 | 基础概率 | 主色 | 内容 | 演出强度 |
| --- | --- | --- | --- | --- | --- |
| N | 云朵 | 60% | 雾蓝 / 纸白 | 星尘 ×5 + 云朵兽贴纸 | 轻：卡片飘出 + 小彩纸 |
| R | 荧光 | 28% | 荧光青 | 角色贴纸（图鉴卡） | 中：翻面 + 边缘霓虹扫光 |
| SR | 电波 | 10% | 电光紫 / 热粉 | 全息闪卡 + 小确幸券 | 强：去色闪切 + 速度线 + 震屏 |
| SSR | 传说 | 2% | 熔金 / 琥珀 | 皇冠星兽 + 大愿望券 | 仪式：压暗 → 心跳 → 光柱 → 分格闪切 → 金雨 → 印章 |

### 温柔保底（关键）

- 连续 **5 次**没出 SR 及以上 → 第 6 次必出 SR 或 SSR。
- 连续 **15 次**没出 SSR → 第 16 次必出 SSR。
- 保底进度在图鉴页可见（「再拆 2 次，电波级一定会来」），把等待变成期待，而不是黑箱。
- **没有空盒**。最差也是星尘 + 贴纸。

### 奖池内容

- **图鉴 32 张**：4 个系列 × 8 张。
  - 云朵朋友 / 街角小怪兽 / 电波乐队 / 星冠家族
- **重复处理**：自动转星尘（N +5 / R +15 / SR +40 / SSR +100），并弹出「又见面啦」而不是「重复」。
- **星尘商店**：120 星尘换指定 R，320 换指定 SR。**SSR 不可兑换**，只能抽到或保底，保住稀有性的重量。
- **系列奖励**：集齐一个系列 → 解锁一款盲盒皮肤（贴纸风格换色）。

### 实体愿望券（把屏幕里的惊喜落到生活里）

| 档位 | 券 | 默认内容（家长可改） |
| --- | --- | --- |
| SR | 小确幸券 | 多听一个睡前故事 / 一起烤饼干 / 挑一部动画片 |
| SSR | 大愿望券 | 去一次公园 / 一起做手工 / 自己点一顿饭 |

家长在家长台点「已兑现」，券盖上 `DONE` 章。这让抽奖结果变成亲子约定，而不是虚拟数值。

## 4. 开箱流程与演出

### 四个动作

1. **选盒**：货架 6 盒，缓慢呼吸浮动；选中放大 1.08 并盖一枚 `SELECTED` 斜章。
2. **摇盒**：长按摇 3 下，盒子左右抖、内部「咔哒」、进度环走满；摇得越久，粒子越密（上限封顶，不诱导过量操作）。
3. **撕封条**：按住封条往下拖，纸屑粒子 + 撕裂音；封条断开后盒子轻微弹一下。
4. **开盖**：盖子 3D 掀起，光柱冲出，镜头推近 8%，进入稀有度演出。

### 传说级演出时间轴（总长 2.6s）

| 时间 | 画面 | 声音 |
| --- | --- | --- |
| 0.0–0.3s | 全场压暗至 20%，只剩盒缝一线光 | 环境音抽空 |
| 0.3–0.9s | 心跳三下，光随心跳胀缩 | 低频鼓点 ×3 |
| 0.9–1.2s | 光柱炸开，金色粒子喷出 | 上升音效 |
| 1.2–1.6s | 三帧漫画分格闪切（剪影 → 眼睛 → 全身） | 快门声 |
| 1.6–2.0s | 皇冠印章从上方砸下，震屏 6px | 重物落地 |
| 2.0–2.4s | 卡片 360° 展示，全息反光扫过 | 铃音 |
| 2.4–2.6s | 卡片飞入图鉴图标，进度 +1，金光收束 | 收束音 |

> 护眼约束：无高于 2Hz 的闪烁；闪切用「去色 + 硬切」而非频闪；金雨粒子 ≤ 120 个，可在安静模式关闭。

## 5. 收藏

- **图鉴**：4 系列标签页，8 格网格；未获得显示剪影 + 问号；已获得显示卡面 + 编号。
- **系列进度条**：`5 / 8`，集齐时整格盖章 `COMPLETE`。
- **卡片详情**：点击卡面翻转，背面写一句性格设定（如「金冠星龙：喜欢把星星藏在耳朵里」），给 6 岁孩子一个可复述的故事。
- **总进度**：顶部 `12 / 32`，达到 8 / 16 / 24 / 32 时各给一次全屏庆祝。

## 6. 补货与重置

### 补货
- 货架 6 格，每开走一盒留下空格，空格里显示「补货中」的虚线框。
- 家长点「补货」→ 新盒从左上方滑入落位，带「咔哒」落位音。
- 可设置「本机剩余稀有名额」：显示 `今日还剩 1 个传说`。这是刻意设计的期待感，不是作弊。
- 补货只补盒子，不动图鉴与星尘。

### 重置（两级，防误触）
| 操作 | 影响 | 保护 |
| --- | --- | --- |
| 补满货架 | 只补盒子 | 单击即可 |
| 重开一局 | 清空图鉴 / 星尘 / 保底计数 | 长按 3 秒 → 输入 4 位家长密码 |
| 恢复默认设置 | 次数、券内容、皮肤 | 长按 3 秒 |

> 孩子端没有任何「重置」入口；家长台入口在首页右下角，用一枚小齿轮，双击才打开。

## 7. 视觉系统

### 参考与转译

参考《绝区零》的视觉语言：街头涂鸦 + 波普、CRT 显像管电视、高饱和霓虹、粗黑描边、贴纸拼贴、斜切构图、半调网点、错位套色、大字号压缩标题、漫画分格、速度线、故障与扫描线。

做儿童化转译，保留「酷」，去掉「躁」：

| 保留 | 软化 |
| --- | --- |
| 粗描边、贴纸白边、网点 | 降低故障强度，不做频闪 |
| 斜切、错位、拼贴 | 圆角加大、信息层级只留 2 层 |
| 霓虹 + 深色底 | 颜色糖果化，避免脏灰 |
| 大字号 + 印章 | 正文用圆体，不用锐利宋体 |
| CRT 扫描线 | 不透明度压到 6%，静态 |

### 视觉公式

```
街头涂鸦海报 × CRT 电视屏幕 × 贴纸白边 × 霓虹三色 + 圆角软化
```

### 色板

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| ink | `#0B0A14` | 主背景（偏紫的黑，不死黑） |
| panel | `#14121F` | 面板 / 卡片底 |
| lime | `#D6FF3F` | 主色：按钮、强调、选中 |
| cyan | `#35F2E0` | 稀有 / 数据 |
| purple | `#A855F7` | 史诗 / 次强调 |
| pink | `#FF4D9D` | 点缀、贴纸 |
| gold | `#FFC93C` | 传说专用，其它地方禁用 |
| paper | `#FFF8E7` | 文字主色 / 贴纸底 |

### 字体

- 中文标题：思源黑体 Heavy / 苹方 Semibold（回退）——粗、方、压缩。
- 拉丁标题：Archivo Black（数字与代号）。
- 标签 / 编号：Space Grotesk / 等宽，全大写 + 字距 +0.12em。
- 正文：系统圆体系（苹方 / 微软雅黑），行高 1.7。

### 纹理与组件

- 网点：`radial-gradient` 6px 循环，透明度 6%。
- 扫描线：横向 4px 循环，透明度 3%。
- 贴纸：白边 4px + 黑描边 + 轻微旋转。
- 胶带：半透明纸色斜条，压在卡片角上。
- 卡片：切角 `clip-path`，硬投影（无模糊）。
- 印章：红/荧光色斜章，2° 旋转，带噪点遮罩。

## 8. 动效规范

| 项 | 值 |
| --- | --- |
| 主缓动 | `cubic-bezier(.16,1,.3,1)`（outExpo） |
| 弹跳 | `cubic-bezier(.34,1.56,.64,1)` |
| UI 反馈 | 120–240ms |
| 镜头 / 转场 | 480–720ms |
| 开箱仪式 | 1600–2600ms |
| 错峰 | 40ms / 层 |
| 呼吸浮动 | 3.2s，位移 4px，`inOutSine` 循环 |
| 震屏 | 6px，120ms，衰减 3 次 |
| 粒子 | ≤ 120 个，canvas，重力 0.04 |

**安静模式**：关闭粒子与震屏，仪式的闪切改为淡入，时长 ×0.6。首页右下角可切换。
